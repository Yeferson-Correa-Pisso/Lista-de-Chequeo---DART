# VerificacionDart — EA1 Fundamentos de Programación en Dart

Lista de chequeo digital para verificar modelos de análisis (SENA - ADSO, ficha 3410385).

## Estructura

| Archivo | Ejercicio |
|---|---|
| `lib/criterio.dart` | 1 y 2 — clase `Criterio` |
| `lib/modelo_analisis.dart` | 3 a 7 — clase `ModeloAnalisis` |
| `lib/verificacion.dart` | 8 y 9 — clase `Verificacion` |
| `bin/ejercicio_01_criterio.dart` ... `bin/ejercicio_09_resumen.dart` | Prueba individual de cada ejercicio |
| `bin/verificacion_dart.dart` | 10 — integración con los cuatro modelos |

## Ejecución

```
dart pub get
dart run bin/ejercicio_01_criterio.dart   # (y así hasta el 09)
dart run                                   # ejercicio 10 (main)
```
